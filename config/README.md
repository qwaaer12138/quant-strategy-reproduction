## 🛠️ 使用建议

### 1. 策略研发阶段
- 先用**5只代表股票**快速测试策略逻辑：贵州茅台、宁德时代、招商银行、比亚迪、东方财富
- 验证通过后再用**全15只股票**进行全面回测

### 2. 策略验证阶段
- 至少使用**10只以上股票**验证策略普适性
- 重点关注策略在不同行业和风格股票上的表现分化

### 3. 实盘应用阶段
- 选择策略表现最稳定的**3-5只股票**进行实盘跟踪
- 定期（每季度）审查股票池有效性

## 📊 维护规则

### 更新频率
- 每季度末最后一个交易日
- 重大事件时临时调整

### 调整标准
1. **基本面恶化**：连续两个季度亏损或业绩大幅下滑
2. **行业地位丧失**：不再是行业前2名
3. **流动性不足**：连续20日成交额低于5000万
4. **策略表现持续低迷**：连续6个月无法跑赢指数
5. **波动率显著变化**：波动率较历史均值偏离50%以上

### 调整限制
- 每次调整最多更换20%（3只）的股票
- 保持行业和风格分布的均衡性

## 🎯 回测基准

建议使用沪深300指数(000300.SH)作为回测基准：
- 代表市场平均收益水平
- 与股票池风格匹配度高
- 数据历史长，稳定性好
