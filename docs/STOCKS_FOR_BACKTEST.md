# 适合策略回测的A股股票推荐

在量化策略回测中，选择合适的标的股票非常重要。不同类型的策略适合不同特性的股票。

## 🎯 选择标准

适合回测的股票应具备以下特性：
1. **足够的历史数据**：至少3-5年的日线数据
2. **市场关注度高**：流动性好，成交量稳定
3. **趋势或波动特征明显**：策略容易产生有效信号
4. **财务状况稳定**：避免退市风险
5. **代表性强**：行业龙头或典型风格标的

## 💡 回测建议

1. **分策略类型选择**：
   - 趋势跟踪策略优先选高波动率的科技成长股
   - 均值回归策略优先选低波动率的蓝筹银行股
   - 高频交易优先选流动性好的券商股

2. **行业分散**：
   - 回测池应覆盖多个行业
   - 避免单一行业集中度过高

3. **市值分层**：
   - 包含大、中、小市值股票
   - 测试策略在不同市值风格下的表现

4. **动态调整**：
   - 定期更新股票池，剔除基本面恶化标的
   - 根据市场风格变化调整标的权重

## 📝 注意事项

1. **避免财务异常股票**：ST股、亏损股、高质押股
2. **注意交易成本**：低流动性股票可能存在滑点风险
3. **考虑分红拆股**：回测时需要复权处理
4. **退市风险**：优先选择行业龙头和绩优股

建议先从**核心回测池**的10只股票开始，覆盖了主要市场风格和行业。
